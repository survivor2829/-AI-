# 鱼水和 AI 物业助手 Demo 运行与验收

## 打开方式

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本文件所在工程的根目录，即包含 `project.config.json` 的目录。
3. 如果当前账号没有 `project.config.json` 中 AppID 的开发权限，请替换为自己的小程序 AppID 或测试号；本地确定性 Demo 不依赖模型也能走通主流程。

## 建议验收路径

1. 首次进入时，确认底部服务抽屉为半展开，能立即看到“查欠费、装修进度、交房准备”等能力。
2. 点击“查欠费”或输入“帮我查一下物业欠费”，确认抽屉收起为“全部服务”入口。
3. 核对 AI 返回的结构化账单，依次点击“确认缴费”“确认并模拟支付”。
4. 确认出现模拟支付成功状态和电子回执。
5. 点击“全部服务”，确认全屏抽屉可展开，收起后账单与对话状态仍保留。
6. 点击对话页左上角“首页”，确认返回能力发现页并重新显示半展开服务抽屉。

## 接入模型（可选）

云函数 `aiGateway` 支持 OpenAI-compatible 接口，通过云函数环境变量配置：

- `MODEL_BASE_URL`
- `MODEL_API_KEY`
- `MODEL_NAME`

模型只负责意图理解和回复措辞。房屋、账单金额、支付状态和回执均来自确定性业务层；本 Demo 不会产生真实扣款。

## 本地自动检查

在工程根目录运行：

```powershell
npm run demo:test
```

这会检查主流程状态机、抽屉与交易状态隔离、页面结构、事件绑定和关键安全边界。
